# Spotter Freight Prediction

Machine learning pipeline predicting nationwide freight spot rates and December lane rate dynamics for the Spotter ML Engineer Assessment.

## Repository Structure

- `train_and_predict.py`: Main script to train the machine learning model and generate predictions.
- `score.py`: Script to calculate evaluation metrics against the validation set.
- `requirements.txt`: List of Python dependencies required to run the pipeline.
- `data/`: Directory containing the input datasets.
- `scorer_results/`: Directory containing output logs and scoring results.
- `validation_predictions.csv`: Model predictions generated for the validation dataset.
- `december_predictions.csv`: Final forecasted lane rate dynamics for December.
- `validation-predictions-template.csv`: Template format required for validation outputs.
